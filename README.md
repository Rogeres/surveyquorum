# surveyquorum

Consensus screening of survey respondents: a respondent is flagged only when a quorum of independent checks agrees.

Seven signal detectors (open-answer classification, cross-answer coherence, per-question pace, matrix patterns, mass-select, duplicate answers, prototype effort), a weighted evidence layer that turns signals into one of three outcomes — block, review, keep — and an optional LLM arbiter that re-reads every block before it reaches a panel.

The engine source, prompts, calibration harness, agent skills and the numbers behind the talk are being published here. Issues and pull requests are welcome.
