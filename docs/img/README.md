# README figures

Typeset the way GitHub renders Markdown: the system font stack (`-apple-system, "Segoe UI", "Noto Sans", Helvetica, Arial`), 16 px body text, GitHub's light palette (`#1f2328` text, `#d0d7de` borders, `#0969da` accent). Width 880 px, the README column, so the text in a figure is the same size as the text around it.

- `two-places.ru.svg`, `two-places.en.svg` — where sample quality is decided and which tool covers each point.
- `four-levels.ru.svg`, `four-levels.en.svg` — the four levels of answer checks; the English files are string-for-string translations of the Russian ones.
- `examples/problem.ru.gif` — the problem in one animation: four scenes re-typeset from the author's talk; the order and timing of every entrance is copied from the slides (`examples/slides-anim.json`), the last scene embeds the original screen recording.

Everything is generated by `src/figures.py` (SVG for the figures, SVG frames for the animation); frames are rendered with a headless browser and assembled with ffmpeg at 10 fps:

```
python3 src/figures.py build
for f in build/frames/*.svg; do chrome --headless=new --window-size=880,440 --screenshot=${f%.svg}.png "file://$PWD/$f"; done
# segments A, B, C from the frame sequences; D = frame d000 with the recording overlaid at x=44 y=68 w=492; concat; palettegen/paletteuse
```
