# Problem illustration

`problem.ru.gif`: one 28-second animation, four scenes from the author's talk on survey quality control, re-typeset in the README style. Open answers that say nothing, contradictions inside one questionnaire, a card sort with no logic, and a screen recording of a respondent giving up in a Figma prototype (no clicks, two seconds, "very easy"). Entrance order and delays are copied from the deck's slide XML (`slides-anim.json`), not invented. Built by `../src/figures.py`, see `../README.md`.
